# Buddhist Benchmarks

Shared tasks, test data, scorers, and leaderboards for agent skills that work on Buddhist texts. The winning skill for each task and language ships in [BuddhistAI/buddhist-skills](https://github.com/BuddhistAI/buddhist-skills).

- **What is measured, and what is missing:** [STATE.md](./STATE.md)
- **Score your own tool or model:** [SUBMIT.md](./SUBMIT.md)

## Layout

```
tasks/index.json                     every task ID (active or planned)
tasks/<task>/
  TASK.md                            what the task is, input/output format, metrics
  CHANGELOG.md                       every benchmark version and what changed
  scorer/score.py                    one scorer for every language
  data/<lang-code>/v<major>/         test.jsonl (one item per line: id, input, target, metadata)
                                     + README.md (Hugging Face dataset card, exact semver inside)
  results/<lang-code>/LEADERBOARD.md ranked runs for that language
  results/<lang-code>/runs/<run>/    result.json (leaderboard row), outputs, scores.json, run.json
```

Language codes are ISO 639 / BCP 47 (`bo`, `sa`, `pi`, `lzh`, ...), as listed in buddhist-skills [`languages.json`](https://github.com/BuddhistAI/buddhist-skills/blob/main/languages.json).

## Scoring a skill

Every data set is one standard JSONL file: each line is an item with `id`, `input` (the question), `target` (the correct answer) and `metadata`, the same shape Hugging Face datasets, lm-evaluation-harness and Inspect use. Each data folder's README is a Hugging Face dataset card that explains the task with a worked example.

1. Give the skill each item's `input` from `tasks/<task>/data/<code>/v<major>/test.jsonl`, and save its answers as `predictions.jsonl`, one line per item: `{"id": ..., "output": ...}` (format in `TASK.md`).
2. Score it:

   ```bash
   python3 tasks/<task>/scorer/score.py --language <code> \
     --data tasks/<task>/data/<code>/v<major>/test.jsonl \
     --predictions predictions.jsonl > scores.json
   ```

3. Add a run folder with a `result.json` ([docs/results.md](./docs/results.md)) and open a PR. The leaderboards rebuild themselves.

The skill can live anywhere: buddhist-skills `drafts/`, a fork, or another organization's repo. The leaderboard cites its exact commit.

## On Hugging Face

Every released data set is published automatically to the [BuddhistAI](https://huggingface.co/BuddhistAI) org on Hugging Face, one dataset per task and language, tagged with its version, plus a results dataset with every leaderboard run. GitHub stays the source of truth; fix data here, not there. See [docs/huggingface.md](./docs/huggingface.md).

```python
from datasets import load_dataset
ds = load_dataset("BuddhistAI/toc-extraction-tibetan", revision="v2.0.0")
```
