# Design documents

EGM design documents for changes users see in buddhist-benchmarks: one file per change, `<yyyy-mm-dd>-<slug>.md`, started from the [template](https://github.com/BuddhistAI/knowledge-base/blob/main/docs/designs/TEMPLATE.md). List each one in `SITEMAP.md`.

How to write and review a design: [UX reviews with EGM](https://buddhistai.github.io/knowledge-base/handbook/ux.html).
